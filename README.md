## Iniciar

Abre PowerShell en `C:\Proyectos\CorkJobRadar`:

```powershell
.\instalar.ps1
.\iniciar.ps1
```

Visita **http://127.0.0.1:8501**. Si ya está ejecutándose, basta con abrir esa dirección. Para detener la interfaz, Ctrl+C en su terminal; el trabajador de búsquedas es independiente. Cancelar una búsqueda desde la interfaz permite continuarla más tarde.

Si la política de PowerShell bloquea los scripts, puedes usar `instalar.cmd` e `iniciar.cmd`, o los comandos manuales siguientes. No hace falta cambiar la seguridad global ni usar WSL o administrador:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --disable-pip-version-check install --cache-dir data\pip-cache -r requirements-lock.txt
.\.venv\Scripts\python.exe -m corkjobradar doctor
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

El entorno y las dependencias ya están instalados en este equipo. `requirements.txt` fija las dependencias directas; `requirements-lock.txt` registra también las transitivas de esta instalación Windows/Python 3.12. `instalar.ps1` usa este bloqueo. VS Code está instalado; abre únicamente esta carpeta para trabajar en el proyecto.

## Buscar y revisar

1. El catálogo `config/sources.yaml` contiene las URLs comprobadas. Está cargado en la base local. En una instalación vacía, pulsa «Cargar catálogo de fuentes comprobadas» en Fuentes e importación o usa `sources --load`.
2. Pulsa **Buscar todas las ofertas accesibles**. La búsqueda recorre todas las fuentes activadas, sin detenerse por haber encontrado ofertas buenas. Las fuentes no implementadas o restringidas siguen visibles en el catálogo.
3. El progreso de fuentes y tareas se actualiza cada tres segundos. «Actualizar resultados visibles» recarga la tabla de resultados. «Cancelar de forma segura» espera al guardado de la página/tarea en curso.
4. La tabla muestra todas las ofertas por defecto. Los filtros no eliminan registros. «Ficha individual» conserva el texto inglés, análisis español básico, evidencias, incertidumbres, procedencias, snapshots, verificaciones y anotaciones.
5. Para continuar una ejecución cancelada o interrumpida, selecciona su ID en Historial y pulsa **Continuar búsqueda interrumpida**. El bloqueo de archivo impide ejecutar dos trabajadores sobre la misma base.
6. **Exportar todo** genera XLSX, CSV con BOM, JSON y Markdown en `exports/`, además de ofrecer descargas. La exportación contiene todas las ofertas locales y la auditoría de la última ejecución indicada; no es una selección del ranking. Los textos demasiado largos para una celda Excel se conservan por partes en `Textos_largos` y completos en JSON/SQLite.

El botón «Actualizar fuentes» comprueba la primera página de los conectores activados; esa prueba de salud no equivale a recorrer el listado entero. El editor YAML permite modificar o desactivar fuentes y ampliar el catálogo. La importación de catálogos no borra las fuentes ausentes del archivo.

## Comandos disponibles

Desde la raíz, con el Python del entorno virtual:

```powershell
.\.venv\Scripts\python.exe -m corkjobradar doctor
.\.venv\Scripts\python.exe -m corkjobradar sources
.\.venv\Scripts\python.exe -m corkjobradar sources --load
.\.venv\Scripts\python.exe -m corkjobradar sources --refresh
.\.venv\Scripts\python.exe -m corkjobradar scan --all
.\.venv\Scripts\python.exe -m corkjobradar scan --source globetech
.\.venv\Scripts\python.exe -m corkjobradar analyze --pending
.\.venv\Scripts\python.exe -m corkjobradar verify --all
.\.venv\Scripts\python.exe -m corkjobradar export --xlsx
.\.venv\Scripts\python.exe -m corkjobradar audit --run-id 3
.\.venv\Scripts\python.exe -m corkjobradar resume --run-id 1
.\.venv\Scripts\python.exe -m corkjobradar cancel --run-id 1
.\.venv\Scripts\python.exe -m corkjobradar sources --export-file exports\sources.yaml
.\.venv\Scripts\python.exe -m corkjobradar sources --import-file config\sources.yaml
.\.venv\Scripts\python.exe -m pytest -q
```

Sustituye los IDs de ejemplo por los del historial. `scan` exige `--all` o uno o más `--source ID`. La CLI espera al trabajador; la interfaz lo ejecuta en un proceso independiente. La salida informa `completed`, `partial`, `cancelled` o `failed`: un proceso que termina no acredita cobertura completa. `analyze --pending` revisa las ofertas y reutiliza los análisis cuya versión de contenido/perfil/analizador/rutas ya coincide; no repite inferencias innecesarias. `export --xlsx` genera los cuatro formatos juntos.

`import-url URL` importa una URL pública y abre una incidencia `INVESTIGAR_OMISION`. Incluso si falla el acceso, conserva un registro pendiente. `import-csv RUTA` importa columnas `title,url` y opcionalmente `company,location,description,detail_complete,external_id,apply_url`. `detail_complete=true` solo debe utilizarse para descripciones íntegras aportadas lícitamente. Datos de pruebas no deben importarse en producción.

`discover --url URL` lee una página de carreras permitida y registra nuevos ATS enlazados en una cola desactivada para revisión. No usa tokens inventados ni raspa resultados de buscadores. El catálogo admite YAML y CSV (`sources --format csv` para importar/exportar este formato). No hay un límite fijo de empresas en el programa.

## Perfil y transporte

`config/profile.yaml` y la pestaña Perfil permiten editar origen, competencias confirmadas, preferencias y pesos. El origen inicial es **Ballinlough**, sin calle ni coordenadas privadas, **sin coche**, con bicicleta y transporte público. No hay límite de duración de bici/bus por defecto.

IT: el radio de unos 60 minutos en coche es solo referencia geográfica; la accesibilidad real permanece separada. Los fines de semana no se penalizan por sí solos. NO IT: se prioriza lunes a viernes, estabilidad y jornada diurna; fuera de Cork City hace falta evidencia de bicicleta o un único autobús sin transbordos. Las ubicaciones insuficientes se conservan pendientes. El campo estructurado `city=Cork` acredita la localidad publicada, no el tiempo de viaje. «Cork» sin contexto ciudad/condado se mantiene pendiente.

No se consultan rutas ni horarios automáticamente. La ficha admite comprobaciones **manuales** con fuente, destino, acceso a la parada e ida/vuelta compatibles con turno y días. Una declaración manual queda identificada como tal. No se inventa una ruta cuando faltan datos.

Los CV PDF/DOCX se procesan localmente en memoria y solo proponen una lista limitada de competencias. El usuario selecciona y confirma antes de persistirlas; el archivo y su texto completo no se guardan. No se envían candidaturas, correos ni datos a empresas.

El motor gratuito se identifica siempre como `ANALISIS_BASICO / PARCIAL_POR_DATOS`. No sustituye una interpretación semántica exhaustiva en español. La puntuación es provisional, con pesos explícitos y confianza separada. No predice probabilidades de contratación. Ollama tiene un adaptador opcional: requiere modelo instalado y configuración voluntaria `analyzer: ollama` y `ollama_model`. Sus salidas se validan y requieren revisión; **no hay integración en vivo validada en este equipo**. No hay proveedor de IA en la nube implementado ni activado.

Tras editar el perfil, usa «Reanalizar pendientes». Una búsqueda conserva la versión del perfil con la que empezó. Las marcas y solicitudes son apuntes locales; no envían nada.

## Datos, seguridad y recuperación

- Producción: `data/radar.sqlite3`; fixtures: `tests/fixtures`; bases de pruebas: `data/pytest-*`. No hay vacantes sintéticas en producción.
- Errores y auditoría: SQLite, `data/radar.jsonl`, `logs/worker-ID.log` y documentos en `docs/`.
- Antes de una migración de versión existente se crea una copia local. Para una copia manual consistente usa la API `sqlite3.Connection.backup` o detén ambos procesos antes de copiar DB/WAL; no borres la base para reiniciar una búsqueda.
- No publiques `data/`, `exports/`, CV, notas personales ni `.env`; están excluidos de Git.
- Solo HTTP(S), resolución de direcciones públicas, redirecciones revalidadas, límites de tamaño, timeout, reintentos y pausas por dominio. No hay CAPTCHA, inicio de sesión ni proxies de evasión.
- Una página con un widget CAPTCHA en el formulario no se rellena ni envía. Un desafío/bloqueo real detiene el acceso correspondiente. HTTP 403/404 o timeout no significan cierre.
- El límite técnico `safety_max_pages` evita bucles; alcanzarlo produce estado parcial, nunca éxito de cobertura.
